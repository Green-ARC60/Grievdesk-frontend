# GrievDesk - Frontend

A calm, responsive residential society management interface built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite**.

## Features

- **Resident & Staff Portals:** Role-based views for Residents, Committee Members, and Society Secretary.
- **Grievance Management:** Submit, track, prioritize, and resolve maintenance complaints and issues.
- **Resident Directory:** Clean, scannable contact directory with fast search, block filters, and phone copy shortcuts.
- **Notices & Circulars:** Society-wide announcements with pinned notices.
- **Maintenance Dues:** View pending society maintenance dues and track payment records.
- **Real-Time Notifications:** Notification bell for updates, status changes, and announcements.
- **Calm UI Theme:** Sapphire + Gunmetal + Platinum color system with support for Light and Dark modes.

## Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Icons:** Lucide React
- **Routing:** React Router DOM v6
- **HTTP Client:** Axios

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Navigate to the frontend directory:
   ```bash
   cd grievdesk-frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment:
   ```bash
   cp .env.example .env
   ```

4. Start development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
